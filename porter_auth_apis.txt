===================================================
PORTER APP - BACKEND AUTHENTICATION API DOCUMENTATION
===================================================

BASE URL: (Your server URL, e.g., http://localhost:8080)

There are two main ways to authenticate:
1. Phone Number + OTP (Primary flow for Mobile App Customers & Drivers)
2. Email/Phone + Password (Admin/Support flow)

---------------------------------------------------
1. PHONE NUMBER + OTP FLOW
---------------------------------------------------

A. SEND OTP
Endpoint: POST /api/auth/send-otp
Description: Generates and sends a 4-digit OTP to the user's phone.
Headers: Content-Type: application/json
Request Body (Login mode):
{
  "phone": "9876543210",
  "mode": "login"
}
Request Body (Signup mode):
{
  "phone": "9876543210",
  "mode": "signup",
  "name": "John Doe",
  "role": "customer"
}

Success Response (200 OK):
{
  "success": true,
  "requestId": "otp_req_abc123...",
  "expiresInSeconds": 60,
  "maskedPhone": "+91******3210"
}


B. VERIFY OTP
Endpoint: POST /api/auth/verify-otp
Description: Verifies the OTP. On success, creates the user (if signup) and returns JWT tokens.
Headers: Content-Type: application/json
Request Body:
{
  "phone": "9876543210",
  "otp": "1234",
  "requestId": "otp_req_abc123..."
}

Success Response (200 OK):
{
  "success": true,
  "accessToken": "eyJhbGciOiJIUzI1NiIs...",
  "refreshToken": "eyJhbGciOiJIUzI1NiIs...",
  "user": {
    "id": "1",
    "name": "John Doe",
    "phone": "9876543210",
    "email": null,
    "isPhoneVerified": true
  }
}


C. RESEND OTP
Endpoint: POST /api/auth/resend-otp
Description: Resends a new OTP for an existing session (max 5 attempts).
Headers: Content-Type: application/json
Request Body:
{
  "requestId": "otp_req_abc123..."
}

Success Response (200 OK):
{
  "success": true,
  "requestId": "otp_req_new456...",
  "expiresInSeconds": 60,
  "maskedPhone": "+91******3210"
}


---------------------------------------------------
2. PASSWORD BASED FLOW (ADMIN/DASHBOARD)
---------------------------------------------------

A. LOGIN WITH PASSWORD
Endpoint: POST /api/auth/login
Description: Authenticate using either an email or phone number + password.
Headers: Content-Type: application/json
Request Body (Email):
{
  "email": "admin@porterapp.com",
  "password": "securepassword"
}
Request Body (Phone):
{
  "phone": "9876543210",
  "password": "securepassword"
}

Success Response (200 OK):
{
  "success": true,
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "user": {
    "name": "Admin User",
    "role": "Admin",
    "email": "admin@porterapp.com",
    "phone": "9876543210",
    "avatar": "https://api.dicebear.com/7.x/initials/svg?seed=Admin"
  }
}


B. SIGNUP WITH PASSWORD
Endpoint: POST /api/auth/signup
Description: Register a new account with a password (typically used for support/admin).
Headers: Content-Type: application/json
Request Body:
{
  "fullName": "Admin User",
  "email": "admin@porterapp.com",
  "phone": "9876543210",
  "company": "Company XYZ",
  "role": "Admin",
  "password": "securepassword"
}

Success Response (200 OK):
{
  "success": true,
  "message": "Account created successfully. You can now login."
}
