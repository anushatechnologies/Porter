ANUSHA PORTER ADMIN PANEL API HANDOFF
=====================================
Base URL: https://api.anushaporter.com

AUTHENTICATION
==============
1. Login:
POST /api/auth/login
Body: {"email":"admin@example.com","password":"<password>"}
Response contains:
{"success":true,"token":"<ADMIN_JWT>","user":{"id":1,"role":"Super Admin"}}

2. Add this header to every admin request:
Authorization: Bearer <ADMIN_JWT>
Content-Type: application/json

3. All IDs below are database IDs unless the endpoint explicitly says bookingId.

PRICING ENGINE
==============
GET /api/admin/pricing/vehicles
Returns all pricing vehicles for the management table.

GET /api/pricing/vehicle/{vehicleId}
Example: GET /api/pricing/vehicle/tata-ace

POST /api/pricing
Body:
{
  "vehicleId":"tata-ace",
  "name":"Tata Ace",
  "icon":"truck",
  "capacityKg":750,
  "volume":4.5,
  "minDistance":1,
  "maxDistance":100,
  "baseFare":450,
  "pricePerKm":18,
  "minFare":450,
  "maxFare":5000,
  "status":true,
  "priority":1,
  "commissionPercentage":10
}

PUT /api/pricing/vehicle/{vehicleId}
Uses the same body as POST /api/pricing.

ORDER AND DRIVER ACTIONS
========================
POST /api/orders/{id}/assign
Body:
{
  "driverId":"12",
  "driverName":"Ramesh Kumar",
  "driverPhone":"9876543210",
  "driverVehicleNumber":"TS09EA1234"
}
Response: {"success":true,"order":{...}}

POST /api/orders/{id}/status
PUT /api/orders/{id}/status
Body: {"status":"accepted"}
Supported examples: assigned, accepted, picked_up, transit, delivered, cancelled.

POST /api/drivers/{id}/verify
No body required.
Response: {"success":true,"driver":{..."kyc":"verified"}}

POST /api/drivers/{id}/reject
No body required.
Response: {"success":true,"driver":{..."kyc":"rejected"}}

DELETE /api/admin/drivers/{id}
DELETE /api/drivers/{id}
No body required. Supports numeric ID (e.g. 12), formatted ID (e.g. DRV-12), phone, or email.
Removes driver profile from database and purges uploaded document storage in S3.
Response: {"success":true,"message":"Driver profile removed successfully","driverId":"12"}

FINANCE AND WALLET MANAGEMENT
==============================
1. Modify Driver Wallet Balance:
PUT /api/admin/drivers/{id}/wallet
POST /api/admin/drivers/{id}/wallet
PUT /api/drivers/{id}/wallet
Body (Set Exact Balance):
{
  "walletBalance": 500.0,
  "action": "set",
  "reason": "Admin balance adjustment"
}
Body (Credit/Add Funds):
{
  "amount": 200.0,
  "action": "credit",
  "reason": "Trip bonus incentive"
}
Body (Debit/Deduct Funds):
{
  "amount": 50.0,
  "action": "debit",
  "reason": "Manual penalty"
}
Response:
{
  "success": true,
  "driverId": "DRV-12",
  "action": "set",
  "previousBalance": 0.0,
  "netChange": 500.0,
  "walletBalance": 500.0,
  "status": "online",
  "transactionId": "TXN_W_1725280000",
  "message": "Driver wallet updated successfully"
}

2. Modify Customer Wallet Balance:
PUT /api/admin/customers/{id}/wallet
POST /api/admin/customers/{id}/wallet
PUT /api/customers/{id}/wallet
Body:
{
  "walletBalance": 350.0,
  "action": "set"
}
Response:
{
  "success": true,
  "id": 12,
  "action": "set",
  "previousBalance": 100.0,
  "walletBalance": 350.0,
  "wallet": 350.0,
  "message": "Customer wallet updated successfully"
}

3. Customer Top-Up (Legacy / Quick Top-up):
POST /api/customers/{id}/topup
Body: {"amount": 500}
Response: {"success": true, "wallet": 500, "walletBalance": 500}

4. Unified Admin Wallet Modify Endpoint:
POST /api/admin/wallet/modify
Body:
{
  "userType": "driver", // or "customer"
  "id": "12",
  "amount": 500.0,
  "action": "set", // "set", "credit", "debit", or "adjust"
  "reason": "Administrative adjustment"
}
Response: {"success": true, "walletBalance": 500.0, ...}

5. Minimum Wallet Balance Policy for All Drivers (Default: ₹1000.0):
GET /api/admin/wallet/minimum-balance
GET /api/admin/settings/wallet/minimum-balance
Response:
{
  "success": true,
  "minRequiredBalance": 1000.0,
  "minimumBalance": 1000.0
}

PUT /api/admin/wallet/minimum-balance
PUT /api/admin/settings/wallet/minimum-balance
POST /api/admin/settings/wallet
Body (Update minimum threshold):
{
  "minimumBalance": 1000.0,
  "applyToExistingDrivers": false // set true to also elevate all existing drivers whose balance < 1000.0
}
Response:
{
  "success": true,
  "minRequiredBalance": 1000.0,
  "minimumBalance": 1000.0,
  "appliedToExistingDrivers": false,
  "message": "Minimum wallet balance updated to ₹1000.0 for all drivers"
}

POST /api/payouts/{id}/release
No body required.
Response: {"success":true,"status":"settled"}

COMMON ERRORS
=============
401: missing, invalid, or expired Authorization token.
400: invalid body or validation failure.
404: requested ID does not exist.
409: duplicate account data.
500: backend/database/deployment error.

POSTMAN TESTING
===============
Create a Postman environment:
baseUrl = https://api.anushaporter.com
adminToken = token returned by /api/auth/login

Use URL: {{baseUrl}}/api/admin/pricing/vehicles
Header: Authorization = Bearer {{adminToken}}

If pricing returns 401, the token is missing or expired.
If pricing returns 404, the production container is running an old image and must be rebuilt/deployed.
The admin panel must use /api/admin/pricing/vehicles, not /api/vehicles, for pricing management.
