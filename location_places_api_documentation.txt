===================================================================
ANUSHA PORTER - LOCATION & GOOGLE PLACES API DOCUMENTATION
===================================================================
Base URL: https://api.anushaporter.com

This document describes the 2 Google Places endpoints implemented in the backend:
1. Autocomplete Search Endpoint (/api/location/autocomplete or /api/places/autocomplete)
2. Place Details Coordinates Endpoint (/api/location/details or /api/places/details)

-------------------------------------------------------------------
1. PLACE AUTOCOMPLETE SEARCH ENDPOINT
-------------------------------------------------------------------
Method: GET
URLs:
  - https://api.anushaporter.com/api/location/autocomplete?input={query}
  - https://api.anushaporter.com/api/places/autocomplete?input={query}

Query Parameters:
  - input (string, e.g. Cyber Towers, DLF Gachibowli, Road No 36 Jubilee Hills, Apollo Hospital)
  - q (optional string alias for input)

Example Request:
  GET https://api.anushaporter.com/api/location/autocomplete?input=Cyber%20Towers

Example Response (200 OK):
{
  "success": true,
  "predictions": [
    {
      "placeId": "ChIJbU60yXA_zjsRkW54uoW_aN4",
      "primaryText": "Cyber Towers",
      "secondaryText": "Hitech City, Madhapur, Hyderabad, Telangana",
      "fullText": "Cyber Towers, Hitech City, Madhapur, Hyderabad, Telangana"
    },
    {
      "placeId": "ChIJD7fiBh9NyzsRSc0un6448zo",
      "primaryText": "DLF Cyber City",
      "secondaryText": "Gachibowli, Hyderabad, Telangana",
      "fullText": "DLF Cyber City, Gachibowli, Hyderabad, Telangana"
    }
  ]
}

-------------------------------------------------------------------
2. PLACE DETAILS (COORDINATES) ENDPOINT
-------------------------------------------------------------------
Method: GET
URLs:
  - https://api.anushaporter.com/api/location/details?placeId={placeId}
  - https://api.anushaporter.com/api/places/details?placeId={placeId}

Query Parameters:
  - placeId (string, e.g. ChIJbU60yXA_zjsRkW54uoW_aN4)
  - place_id (optional string alias for placeId)

Example Request:
  GET https://api.anushaporter.com/api/location/details?placeId=ChIJbU60yXA_zjsRkW54uoW_aN4

Example Response (200 OK):
{
  "success": true,
  "data": {
    "placeId": "ChIJbU60yXA_zjsRkW54uoW_aN4",
    "name": "Cyber Towers",
    "formattedAddress": "Cyber Towers, Hitech City Main Rd, Patrika Nagar, HITEC City, Hyderabad, Telangana 500081",
    "lat": 17.4504,
    "lng": 78.3811
  }
}

-------------------------------------------------------------------
3. REVERSE GEOCODING (LAT/LNG TO ADDRESS)
-------------------------------------------------------------------
Method: GET
URL: https://api.anushaporter.com/api/location/reverse?lat={lat}&lng={lng}

Example Request:
  GET https://api.anushaporter.com/api/location/reverse?lat=17.4504&lng=78.3811
===================================================================
