================================================================================
           ANUSHA PORTER - CUSTOMER SERVICES & CATEGORIES API SPECIFICATION
================================================================================

BASE URL: https://api.anushaporter.com
AUTHENTICATION:
- Customer endpoints: PUBLIC (No token required)
- Admin endpoints: Protected (Authorization: Bearer <admin_jwt_token>)

================================================================================
1. PRIMARY ENDPOINT: GET /api/customer/services
================================================================================

HTTP METHOD: GET
ENDPOINT: /api/customer/services
ACCESS: Public (Guest & Authenticated Users)

PURPOSE:
Returns all active categories with their active, customer-visible services grouped
together and sorted by displayOrder ASC. Ideal for home screens and dynamic category
tabs.

BACKEND LOGIC:
1. Fetches all active categories (`isActive = true`), sorted by `displayOrder ASC`.
2. Fetches all active services (`customerAppVisible = true` AND `isActive = true`),
   sorted by `displayOrder ASC`.
3. Groups services under their corresponding category.
4. Filters out any categories that contain 0 visible services.
5. Returns a structured JSON payload.

SAMPLE REQUEST:
GET /api/customer/services HTTP/1.1
Host: api.anushaporter.com
Accept: application/json

================================================================================
2. ENRICHED FLAT ENDPOINTS (FALLBACKS & HOME FEED)
================================================================================

1) GET /api/services
Returns flat list of all active services with enriched category info.
Response includes:
- `categoryId`: "1", "2", "3"
- `categoryName`: "Porter Trucks & Fleet", "2 Wheeler / Bike", etc.
- `customerAppVisible`: true / false
- `displayOrder`: 1, 2, 3...
- `imageUrl`: string
- `capacityKg`: number
- `basePrice`: number
- `perKmRate`: number
- `eta`: string

2) GET /api/home
Customer App main feed returning `featuredServices`, `services`, `announcements`,
`defaultPickupAddress`, and `user` profile info.

================================================================================
3. CATEGORY MANAGEMENT ENDPOINTS (PUBLIC & ADMIN)
================================================================================

1) GET /api/categories OR GET /api/admin/categories
Query params:
- `all=true` : returns both active and inactive categories (Admin)
- `all=false` (default): returns active categories only

Response:
{
  "success": true,
  "count": 3,
  "categories": [
    {
      "id": 1,
      "name": "Porter Trucks & Fleet",
      "slug": "porter-trucks-fleet",
      "icon": "truck-fast",
      "description": "Mini trucks, tempos, and commercial flatbeds",
      "displayOrder": 1,
      "isActive": true
    },
    ...
  ]
}

2) POST /api/admin/categories
Headers: Authorization: Bearer <admin_token>
Body:
{
  "name": "Heavy Machinery Transport",
  "slug": "heavy-machinery",
  "icon": "crane",
  "description": "Transport for construction and heavy industrial equipment",
  "displayOrder": 4,
  "isActive": true
}

3) PUT /api/admin/categories/{id}
Updates existing category properties.

4) PATCH /api/admin/categories/{id}/toggle-status
Toggles category isActive status.

5) DELETE /api/admin/categories/{id}
Deletes a category.

================================================================================
4. FIELD DICTIONARY
================================================================================

CATEGORY OBJECT:
- `id` (String/Long)          : Unique identifier (e.g. "1")
- `name` (String)             : Display name (e.g. "Porter Trucks & Fleet")
- `slug` (String)             : URL-friendly identifier (e.g. "porter-trucks-fleet")
- `icon` (String)             : Icon name or URL (e.g. "truck-fast", "motorbike")
- `displayOrder` (Integer)    : Position index for sorting (1, 2, 3...)
- `isActive` (Boolean)        : Category active/inactive status

SERVICE OBJECT:
- `id` / `serviceId` (String) : Service identifier (e.g. "tata-ace", "two-wheeler")
- `name` (String)             : Full display name (e.g. "Tata Ace – Mini Truck (750 Kg)")
- `categoryId` (String)       : Parent category ID ("1", "2", "3")
- `categoryName` (String)     : Parent category name ("Porter Trucks & Fleet")
- `description` (String)      : Customer-facing description
- `imageUrl` / `iconUrl`      : Full image URL
- `capacity` (String)         : Formatted capacity label (e.g. "750 kg", "20 kg")
- `capacityKg` (Integer)      : Numeric payload weight limit in Kg (750, 20)
- `basePrice` / `baseFare`    : Base booking fare in currency units (e.g. 210.0)
- `perKmRate` / `pricePerKm`  : Distance rate per Km (e.g. 18.0)
- `eta` / `etaLabel`          : Estimated arrival string (e.g. "5 mins")
- `displayOrder` (Integer)    : Sorting order within category
- `customerAppVisible` (Bool) : Whether shown in customer app (default true)
- `isActive` (Boolean)        : Global service enable/disable flag
