1. AUTHENTICATION & PROFILE APIS
================================================================================

1.1 SEND OTP (PHONE / EMAIL)
--------------------------------------------------------------------------------
Endpoint: POST /api/auth/send-otp
Auth: None (Public)
Description: Sends a 6-digit OTP to the customer's phone number or email for login/signup.

Request Headers:
  Content-Type: application/json

Request Body:
{
  "phone": "9876543210"
}
(Also accepts: "phoneNumber", "mobile", or "email")

Response (200 OK):
{
  "success": true,
  "message": "OTP sent successfully.",
  "otp": "123456",
  "phone": "9876543210",
  "expiresIn": 300
}


1.2 RESEND OTP
--------------------------------------------------------------------------------
Endpoint: POST /api/auth/resend-otp
Auth: None (Public)
Description: Resends the OTP to the specified phone number.

Request Body:
{
  "phone": "9876543210"
}

Response (200 OK):
{
  "success": true,
  "message": "OTP resent successfully.",
  "otp": "123456",
  "expiresIn": 300
}
