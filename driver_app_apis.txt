  1. AUTHENTICATION & ONBOARDING
================================================================================

1.1 CREATE ACCOUNT / SIGNUP
---------------------------
POST /api/auth/signup
Body:
{
  "fullName": "Rajesh Kumar",
  "email": "rajesh@example.com",
  "phone": "9876543210",
  "password": "securepass",
  "company": "Porter Partner Network",
  "role": "Driver"

================================================================================
  2. FILE UPLOADS
================================================================================

2.1 UPLOAD IMAGE (Selfie, Aadhaar, License, etc.)
-------------------------------------------------
POST /api/upload/image
Content-Type: multipart/form-data
Body:
  file: (binary image file)
  category: "profile" | "aadhaar" | "license" | "rc" | "bankpassbook"

{
  "url": "https://poteranusha.s3.ap-south-2.amazonaws.com/profile/uuid.jpg"

================================================================================
  3. DASHBOARD, PROFILE & STATUS
================================================================================

3.1 FETCH DRIVER PROFILE (By Email)
-----------------------------------
GET /api/drivers/email/{email}
(Example: GET /api/drivers/email/rajesh%40example.com)

Response: 
{
  "id": 1001,
  "name": "Rajesh Kumar",
  "kyc": "verified", // "verified" | "pending" | "rejected"
  "rejectedReason": "", // Filled if kyc = "rejected"
  "rating": "4.8", // string
  "status": "online", // "online" | "offline"
  ...all other driver fields
}

3.2 TOGGLE ONLINE / OFFLINE STATUS
----------------------------------
PUT /api/drivers/email/{email}/status
Body:
{
  "status": "online" // or "offline"
}
Response: The updated Driver JSON object.

================================================================================
  4. ORDERS, TASKS, AND EARNINGS
================================================================================

4.1 POLL FOR ACTIVE ORDERS (Run every 5s while online)
------------------------------------------------------
GET /api/drivers/{email}/orders/active

Response (If assigned an order):
{
  "id": 601,
  "status": "assigned",
  "pickupAddress": "Koramangala, Bangalore",
  "dropAddress": "BTM Layout, Bangalore",
  "amount": 245,
  ...
}
Response (If NO active order):
{}

4.2 FETCH ORDER HISTORY (Tasks & Earnings)
------------------------------------------
GET /api/drivers/{email}/orders/history

Response:
[
  {
    "id": 501,
    "status": "completed",
    "amount": 185,
    "createdAt": "2026-07-28T08:30:00Z",
    ...
  }
]
Note: Calculate earnings locally by summing the 'amount' field.

4.3 UPDATE ORDER STATUS (During Delivery)
-----------------------------------------
PUT /api/orders/{orderId}/status
Body:
{
  "status": "accepted" // "accepted", "picked_up", "transit", "completed"
}
Response: Updated Order JSON object.

5.3 APPROVE / REJECT DRIVER KYC
-------------------------------
PUT /api/admin/drivers/{driverId}/kyc
Body (Approve):
{
  "status": "verified"
}
Body (Reject):
{
  "status": "rejected",
  "reason": "Image is blurry"
}
Response: { "success": true, "driverId": "1001", "kycStatus": "verified" }
